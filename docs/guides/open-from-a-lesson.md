# Run and open code from a lesson

Lessons on [kevsrobots.com](https://www.kevsrobots.com/) and other sites can run their code examples with Snakie, right on the page. When you want to keep the code and change it, **Open in Snakie** takes it into the full app.

## Press play on a lesson's code

Many lesson code blocks have a green **play** button. Press it and a small output panel pops up under the code:

- the program's output, in a live REPL you can keep typing into,
- the board, with its pins lit while the program drives them.

Nothing is installed and no board is needed: the code runs on Snakie's [simulator](../explanation/simulator.md), in your browser. The panel has **Run again**, **Stop** and a close button, and the play button turns into a stop button while the program runs.

Some pages go one step further and turn a code block into a live Snakie box where it stands, so you can edit the code and run it on the page.

!!! note "Can't run a block?"
    A very long example may be too big to run on the page. Use **Open in Snakie** instead.

## Open the code in Snakie

**Open in Snakie** opens the lesson's code as a new, unsaved tab in the full app, so you can change it, save it, and run it on a real board.

- **In the web app**, it opens [app.snakie.org](https://app.snakie.org/) in a new browser tab.
- **In the desktop app**, it opens the code in Snakie on your computer, if you have it [installed](../get-started/install.md). If Snakie is already running, its window comes forward with the new tab, instead of a second copy starting.

Snakie always switches to the **Code** workspace for it, even if you were last working in Electronics or Build. The tab keeps the lesson's file name, for example `blink.py`.

If you edited the code on the page first, your version is the one that opens, and Snakie says it was *edited from the original*.

!!! tip "Nothing is saved until you say so"
    The opened code is an unsaved tab. Save it with **Cmd/Ctrl+S** to keep it on your computer or your board.
